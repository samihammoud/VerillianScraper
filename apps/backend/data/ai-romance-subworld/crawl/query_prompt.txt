You choose the next {QUERIES_PER_ROUND} TikTok search queries for a crawler mapping
AI-generated romance/couple video content specifically — story series and skits with
AI-rendered or AI-voiced characters, not real people. This is about the content
itself (AI-rendered characters and story arcs), not AI dating apps, companion
chatbots, or people talking about using AI to date — those are a different topic.

The goal is a corpus in which topics can be RANKED against each other. That needs
two things at once, and a query that serves neither is wasted:
  - enough distinct topics that there is something to compare
  - enough posts per topic that its median view count is stable (~25+)

A query that finds 40 accounts all covering a topic already well represented below
adds nothing. Neither does one that adds a topic so narrow it will only ever have
three posts.

Return exactly {QUERIES_PER_ROUND} queries: {N_EXPLOIT} with intent "exploit" and {N_EXPLORE} with intent "explore".

- exploit: deepen a story arc, genre, or series style that actually appeared in the
  videos, listed below. Narrow it to a more specific angle inside it rather than
  restating it.
- explore: reach for an AI-romance story arc, genre, or series style that no past
  query and no observed topic covers. Vary the specific angle each round (a story
  arc, a genre/theme, a particular series style) rather than repeating the same
  phrase round over round.
- Never reword a past query. A query that means the same thing as one already in
  the list is wasted, even with different wording.
- A past query with 0 handles found is a dead vein. Do not go near it again.
- Queries are what a person types into TikTok search: short, lowercase, no
  punctuation, no boolean operators, no hashtags.
- Ignore the products line in the evidence below. This world is about AI-rendered
  people and story arcs, not goods; that line is expected to be empty and is not
  a signal.
- The formats line is informational only — it describes how existing videos are
  shot (talking head, podcast clip, skit), not something a TikTok search can
  target. Never build a query around a format term; only topic terms are
  exploitable.
- Every query must target AI-generated romance video content specifically. If a
  query would return the same results without the word "ai" or an equivalent
  (avatar, generated, virtual character, etc.), it does not belong in this world.
